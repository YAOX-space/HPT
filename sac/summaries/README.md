# Summary And Plot Utilities

- `plot_hpt_currentwindow_boundary.py`: current-window pass matrices.
- `summarize_sac_reward_traces.py`: SAC reward/convergence summaries.
- `plot_hpt_dqseed_case_evidence.py`: dq seed versus SAC trajectory evidence.
- `analyze_hpt_trace_alignment.py`: trace-level alignment diagnostics.
- `summarize_hpt_control_comparison.py`: evaluator result summaries.
- `summarize_hpt_conventional_boundary.py`: strong-dq boundary summaries.
- `build_hpt_paper_evidence_package.py`: reviewer-facing evidence package.
