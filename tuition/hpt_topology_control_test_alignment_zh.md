# HPT 拓扑、控制策略与建模验收标准对齐说明

本文档用于把当前 tutorial 模型与宋幸论文中的 HPT 构型，以及混合式/混合配电变压器 HDT 文献进行对齐。重点回答一个建模问题：取能换流器到底应该接在哪里，以及模型做到什么程度才算完成。

## 1. 当前最关键结论

对于宋幸论文图 2-4 所采用的 topology，取能换流器不是简单接在一次侧母线，也不是接普通二次侧负载母线，而是接在主电磁变压器的 W3 取能绕组，也可以理解为三次绕组或辅助绕组。

正确结构应为：

```text
一次侧母线 -> 串联耦合变压器 / 调控换流器注入 -> 主变 W1
主变 W2 -> 二次侧母线 / 负载
主变 W3 -> 取能换流器
调控换流器 DC 侧 <-> 公共直流母线 <-> 取能换流器 DC 侧
```

所以我们 tutorial 模型应最终整理成：

- `SeriesTransformer + RegulatingConverter`：位于一次侧串联路径，用来注入补偿电压。
- `EnergyConverter`：只接主变 W3 取能绕组。
- `DCLink`：调控换流器和取能换流器共用的公共直流电容。
- `PrimaryEnergyCoupling`：这个名字不够准确，后续建议改成 `TertiaryEnergyWinding` 或 `EnergyWindingCoupling`。

论文图中容易误解的地方是：W3 画在主变右侧、靠近二次侧 W2，但 W3 不是普通二次侧母线，而是独立的取能绕组。

## 2. HPT/HDT 拓扑家族

文献中常见名称包括 HPT、HDT、hybrid transformer、hybrid distribution transformer、intelligent universal transformer、integrated HDT 等。它们的共同思想是：

```text
工频电磁变压器 + 小容量电力电子换流器
```

也就是说，大部分功率仍由传统电磁变压器承担，电力电子部分只处理补偿功率、调节功率或部分潮流，因此比全功率 SST 更经济。

### 2.1 纯串联型

结构：

```text
电网 -> 串联换流器或串联耦合变压器 -> 工频变压器 -> 负载
```

常见形式：

- 不带耦合变压器，换流器直接串联。
- 通过串联耦合变压器接入。
- 串在高压/中压侧。
- 串在低压侧。
- 使用 AC/AC 矩阵变换器、斩波器或 AC/DC/AC 结构。

主要功能：

- 电压暂降/暂升补偿。
- 电压调节。
- 相角调节。

优点：

- 换流器容量可以较小，因为只需要输出补偿电压。
- 结构和控制目标相对清楚。

缺点：

- 没有独立取能路径时，难以长期交换有功功率。
- 对无功、谐波、电流不平衡的补偿能力有限。
- 串联换流器承受线路电流，电流应力较大。

### 2.2 纯并联型

结构：

```text
电网或负载母线 -> 并联换流器
工频变压器仍承担主功率传输
```

主要功能：

- 无功补偿。
- 功率因数校正。
- 谐波电流补偿。
- 三相电流平衡。

优点：

- 适合做电流型补偿。
- 对电能质量治理比较直接。

缺点：

- 不能直接串联注入电压，因此电压暂降/暂升补偿能力有限。
- 如果涉及有功交换，需要储能或 DC-link 能量管理。

### 2.3 串并联背靠背型

结构：

```text
串联换流器 <-> 公共 DC 母线 <-> 并联/取能换流器
```

并联或取能换流器可以接在：

- 一次侧母线。
- 二次侧母线。
- 独立并联变压器。
- 主变辅助绕组或三次绕组。

主要功能：

- 负载电压调节。
- 电网侧电流整形。
- 功率因数校正。
- 谐波补偿。
- 调控换流器和取能换流器之间有功功率交换。

优点：

- 控制能力最强。
- 功能类似 UPQC 或 UPFC：串联侧管电压，并联/取能侧管电流和 DC-link。

缺点：

- 控制复杂。
- DC-link 电压控制是核心问题。
- 换流器容量、绕组电流、DC 电压约束必须协调。

### 2.4 W3 辅助/三次绕组型

这是与宋幸论文和 Liu 2021 HDT 模型最接近的一类。

结构：

```text
主电磁变压器：
  W1 = 一次绕组
  W2 = 二次绕组
  W3 = 取能绕组 / 三次绕组

串联耦合变压器：
  W4/W5 = 调控换流器与线路之间的串联耦合绕组

换流器：
  取能换流器 -> W3
  调控换流器 -> 串联耦合变压器
  两者共用 DCLink
```

设计逻辑：

- W1/W2 承担大部分功率传输。
- W3 给取能换流器提供一个合适电压等级的磁耦合端口。
- 调控换流器只输出补偿电压。
- 取能换流器维持 DC-link 电压，并可做无功、谐波和电流补偿。

优点：

- 换流器不需要按全变压器容量设计。
- W3 电压等级可以按换流器需要设计。
- 保留传统工频变压器的可靠性。

缺点：

- 需要多绕组主变。
- 绕组变比、极性和接线组别必须正确。
- DC-link 功率平衡必须进入模型。

### 2.5 集成型 IHDT

结构：

```text
单个集成变压器铁心
W1 一次绕组
W2 二次绕组
W3 串联补偿绕组
W4 并联补偿绕组
CVs 串联换流器
CVp 并联换流器
公共 DC 母线，可接 PV/储能/DC-DC
```

设计逻辑：

- 把串联和并联补偿绕组集成到同一个变压器本体中。
- 不再使用额外的串联耦合变压器。
- 在正常运行和故障运行中统一协调电压、电流、功率和设备约束。

优点：

- 相比多个独立变压器方案，可减少铁心材料、绕组数量、体积和成本。
- 更适合做故障穿越和容量协调。

缺点：

- 变压器本体设计更复杂。
- 用通用 Simulink/Simscape 模块搭建更难。
- 必须严肃处理安全运行约束。

## 3. HPT 拓扑演化逻辑

可以粗略理解为以下迭代路线：

1. 传统工频变压器 + 有载调压：可靠、效率高，但调节慢、不连续。
2. 全功率电力电子变压器 SST：控制能力强，但成本高、损耗高、复杂度高。
3. 串联补偿型 hybrid transformer：小容量换流器注入补偿电压，用于电压暂降/暂升。
4. AC/AC 混合补偿型：使用矩阵变换器、斩波器等结构实现电压补偿。
5. 串并联背靠背 HDT：串联换流器和并联换流器共用 DC 母线，可同时管电压和电流。
6. W3 辅助绕组型 HDT：取能换流器通过主变 W3 磁耦合接入，降低直接接母线的电压匹配压力。
7. 集成 IHDT：把串联/并联补偿绕组集成进变压器本体，减少外部耦合变压器。
8. 高级控制 HDT：复合控制、QPR、重复控制、MPC、层级协调控制、故障穿越控制，以及后续可能的强化学习控制。

## 4. HPT 能够做到什么

完整 HPT 模型应能支持以下功能：

- **电压调节**：电网电压暂降或暂升时，维持二次侧/负载电压。
- **无功补偿**：改善电网侧功率因数。
- **谐波治理**：非线性负载下，降低电网侧电流 THD。
- **三相不平衡补偿**：减小负序或零序影响。
- **DC-link 能量平衡**：维持公共直流母线电压稳定。
- **潮流调控**：通过串联/取能换流器交换部分有功功率。
- **故障穿越支撑**：电网故障时支撑负载电压，同时限制绕组和换流器电流。
- **被动退化运行**：换流器退出或旁路时，仍可作为普通工频变压器供电。

## 5. 控制策略整理

### 5.1 等效控制思想

分析时可先等效为：

- 调控换流器 = 受控电压源。
- 取能换流器 = 受控电流源。
- 公共 DC 电容 = 有功能量平衡状态。

核心功率平衡关系是：

```text
P_调控换流器 + P_取能换流器 + dE_dc/dt + 损耗 = 0
```

如果没有储能，HPT 不能长期凭空向电网吸收或释放有功功率，调控换流器和取能换流器之间必须通过 DC-link 达成功率平衡。

### 5.2 取能换流器控制

典型控制层级：

1. 通过 W3 电压或电网侧电压获得 PLL 相角。
2. `abc -> dq` 坐标变换。
3. DC-link 电压外环：

```text
Vdc_ref - Vdc -> PI / filter / feedforward -> i_d_ref
```

4. 无功或功率因数控制：

```text
Q_ref 或 PF_ref -> i_q_ref
```

5. 电流内环：

```text
i_dq_ref - i_dq -> 解耦 PI / PR / QPR -> PWM
```

Liu 2021 的重要结论：

- 纯 PI 可以调住 DC-link 电压。
- 但在负载畸变或不平衡时，纯 PI 可能导致电网电流畸变和不对称。
- 加低通滤波器和陷波器后，电网电流更容易保持正弦和对称。
- 加扰动前馈后，可以减小 DC-link 电压暂态超调。

### 5.3 调控换流器控制

典型控制层级：

1. 测量负载电压或主变二次侧电压。
2. 生成需要注入的串联补偿电压。
3. 三个单相全桥分别控制三相注入电压。
4. 可采用单相 Park 变换、PR/QPR 控制、或者电压前馈 + PI。
5. 输出 SPWM/PWM 触发信号。

核心目标是：

```text
Vload_ref - Vload -> Use_ref -> PWM
```

故障模式下，调控换流器优先承担电压支撑，但必须受调制比、电流、电压和 DC-link 能量约束限制。

### 5.4 多模式协调控制

正常模式：

- 稳定负载电压。
- 稳定 DC-link。
- 改善功率因数。
- 在容量允许时分担无功补偿。

故障模式：

- 第一优先级：换流器和绕组不过流。
- 第二优先级：DC-link 不越界。
- 第三优先级：负载电压支撑。
- 第四优先级：功率因数、谐波、不平衡等电能质量目标。

IHDT 文献中的层级协调控制，会显式引入有功/无功分配系数和安全运行约束，避免某一个换流器或绕组过载。

## 6. 建模设计规范

模型应显式给出这些参数：

- 主变额定容量、频率、W1/W2/W3 变比、接线方式、漏阻抗。
- 串联变压器或串联绕组变比、极性。
- DC-link 标称电压、电容值、初始电压。
- 换流器电压/电流容量。
- 滤波电感或 LC/LCL 滤波器参数。
- PWM 开关频率和采样时间。
- 负载类型：平衡 RL、不平衡 RL、非线性整流负载。
- 控制器参数：Vdc PI、电流环 PI/PR、电压环 PI/PR、滤波器、陷波器、前馈参数。
- 限幅：调制比、电流、绕组电流、DC 电压上下限。

IHDT 文献中可参考的工程规则：

- 滤波电感电流纹波常按额定交流电流的 10%-20% 设计。
- 滤波电容吸收的基波无功功率通常应小于系统额定有功功率的约 5%。
- DC 支撑电容需要按功率阶跃时允许的 DC 电压波动来设计。

## 7. 建模完成验收测试

我建议把 tutorial 模型是否完成，定义为是否通过以下测试。

### Test 0：拓扑完整性测试

通过条件：

- W1 一次绕组、W2 二次绕组、W3 取能绕组清晰可见。
- `EnergyConverter` 的 AC 侧只接 W3。
- `RegulatingConverter` 通过串联变压器或串联绕组接入选定侧。
- 两个换流器共用同一个物理 DC-link。
- 换流器关闭时，主变仍保留普通变压器供电路径。
- 极性测试通过：正向串联注入会导致预期的升压或降压效果。

### Test 1：普通变压器运行测试

工况：

- 换流器关闭。
- 额定电网电压。
- 平衡负载。

通过条件：

- 二次侧电压符合变比。
- 功率流合理。
- 没有悬空节点、物理端口未连接或仿真更新错误。

### Test 2：电压暂降/暂升调节测试

工况：

- 电网电压阶跃到 0.8 pu 和 1.2 pu。
- 平衡负载。

通过条件：

- 负载电压回到参考值附近。
- 串联注入电压没有超过换流器调制和电压限值。
- DC-link 保持在允许范围。

教学模型建议门槛：

- LV RMS 误差 < 5%。
- Vdc 在 0.85-1.15 pu 内。

最终研究模型建议门槛：

- LV RMS 稳态误差 < 2%。
- Vdc 稳态在 0.95-1.05 pu 内。

### Test 3：DC-link 电压控制测试

工况：

- 负载阶跃。
- 电网暂降/暂升。
- 调控换流器工作。

通过条件：

- 取能换流器能把 Vdc 拉回参考值。
- Vdc 不发生长期漂移。
- 有功功率平衡近似成立：

```text
P_series + P_energy + dE_dc/dt ≈ 损耗
```

### Test 4：无功 / 功率因数控制测试

工况：

- 感性负载。
- PF 参考值为 1.0。

通过条件：

- 电网侧功率因数明显改善。
- 取能换流器电流不超过额定值。
- 电压调节仍然有效。

### Test 5：三相不平衡补偿测试

工况：

- 单相负载变化或三相电网不对称。

通过条件：

- LV 电压不平衡度降低。
- 电网侧电流对称性改善。
- 如果 MV 绕组为三角形接法，零序分量不应注入 MV 电网。

### Test 6：谐波治理测试

工况：

- 非线性整流负载。

通过条件：

- 补偿后电网侧电流 THD 低于未补偿状态。
- DC-link 纹波受控。
- 控制器没有引入不稳定振荡。

### Test 7：故障穿越烟雾测试

工况：

- 单相电压跌落。
- 两相电压跌落。
- 三相 50% 电压跌落。

通过条件：

- 故障期间负载电压仍有支撑效果。
- 绕组和换流器电流不超过声明限值。
- Vdc 保持在安全范围内。
- 故障清除后系统恢复。

注意：除非按明确并网规范曲线和电流注入要求验证，否则这个测试只能叫“故障穿越烟雾测试”，不能直接宣称完整 FRT。

### Test 8：被动退化运行测试

工况：

- 关闭 PWM 或旁路换流器。

通过条件：

- 模型表现为普通工频变压器。
- DC-link 或换流器不会导致 AC 网络失败。

## 8. 当前 tutorial 模型意味着什么

目前已经比较接近的部分：

- 一次侧串联路径已经更接近宋幸论文图 2-4。
- 公共 DC-link 概念已经存在。
- 调控换流器已经做到了 H 桥 + PWM 结构。
- 取能换流器模块已经存在，但还不是最终论文式结构。

尚未对齐的部分：

- `main` 需要整理成清楚的 W1/W2/W3 主变结构。
- `EnergyConverter` 必须接到 W3，而不是接一次侧母线代理支路。
- `PrimaryEnergyCoupling` 应改名或重构为 `TertiaryEnergyWinding` / `EnergyWindingCoupling`。
- 取能换流器应从平均 DC 支撑模块，逐步升级为三相桥 + dq 电流控制 + Vdc 外环。
- 应建立持久测试脚本，先覆盖 Test 0-3，再扩展到 Test 4-8。
