# Topology1 Tutorial

This folder keeps only the final tutorial model and its reproducible acceptance
entry points.

- `hpt_topology1_tutorial.slx`: final topology1 tutorial Simulink model.
- `complete_hpt_topology1_tutorial.m`: idempotent completion/update script.
- `run_hpt_topology1_tutorial_tests.m`: tutorial acceptance test runner.
- `hpt_topology1_tutorial_acceptance_report.md`: latest acceptance report.
- `hpt_topology1_tutorial_acceptance_tests.csv`: latest acceptance table.

Intermediate snapshots and early one-off test outputs are archived under
`legacy/tuition_intermediate/`.
