# Debug Escalation Policy

Level 1: path, import, syntax, or configuration issue. Fix and retry once.

Level 2: interface contract issue. Add or repair smoke tests, update migration
notes, and validate producers and consumers.

Level 3: simulation or scientific issue. Preserve artifacts, summarize failure,
and design a narrower experiment.

Level 4: blocked by missing MATLAB/Engine/license/toolbox or repeated solver
failure. Record command, logs, attempted fixes, and the smallest required user
decision.
