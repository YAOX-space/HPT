# Night Autonomous Loop

1. Audit Git and read the research log.
2. Pick the highest-priority unblocked task.
3. Run dry-run or smoke check before long execution.
4. Execute one experiment or one bounded code change.
5. On failure, inspect logs, form a hypothesis, fix once, retry once.
6. If repeated failure remains, write an escalation note and switch to a safer
   documentation or analysis task.
7. Update logs and commit only task-owned source/docs.
8. Continue while producing new evidence.
