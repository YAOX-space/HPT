# NEXT_STEPS — Phase-2 网络压测之后

按"可写进论文 / 仅相量层证据 / 仍需开关级 / 下一步优先级"四档整理。

## 1. 可以写进论文的结论（已验证、可靠）
- **单装置 Mode 5 SAC-HPT 在 IEEE-33 故障传播下的策略级鲁棒性**：连续 OOD 凹陷（Vp 0.027–0.971）、
  800 个多机场景**零无功反号、零 NaN、零异常饱和、无多机不动点失稳**；慢恢复无门控抖振（无噪声）。
- **代表性开关级抽查（10 例，hpt_frt_full.slx，mode=12）通过**：iq 实测峰值 0.308–0.333 全 <0.35，
  超深对称 Vdc>0.75，2ω 纹波对称~0.002/非对称~0.02；与已验证 full-320 m12 一致。
- **缓解措施有效且零成本**：命令 slew 把 C10 振荡 6.2%→2.2%（无 FRT/负荷代价）；安全投影把 survive 99.9→100%。
- **诚实的对比定位**：网络相量层 Mode 5 ≈ 固定律/Mode 6；Mode 5 的优势在**开关级**（m12 82.2% ≫ m7 64.1%）。
  → 论文应把网络测试定位为**鲁棒性验证**，把性能优势归到装置/开关级。

## 2. 只能作为"相量层/策略级"证据（不可声称开关级）
- 全 320/400 场景的 FRT/survive/load 通过率（相量代理，含 Vdc 代理保守性）。
- C10 振荡率与缓解幅度（准静态不动点层面）。
- 负荷穿越率、最低节点电压、受影响节点数（相量潮流）。
- 门控噪声/延迟扫描（L2 代理层，未含开关级测量链路真实噪声谱）。

## 3. 仍需开关级 / 多机联仿确认
- **多机开关级电磁耦合**：本轮 L1 为**单机**抽查；多台 HPT 经网络的快速耦合（环流、PLL 互扰、2ω 互调）未验证。
- **深对称单端口直流预算边界**：相量代理保守（L1 单机 Vdc≈0.87 vs 代理 0.75）；多机深对称下的真实 Vdc 需开关级。
- 逐相不对称串联补偿的开关级波形与限流真实峰值（asym 2ω 链路）。
- 全系统（10 机）开关级运行（本轮仅 10 例代表抽查）。

## 4. 下一步优先级（推荐顺序）
1. **立即部署 slew + 安全投影**（已实现于 `sac_wrapper.HPTController`，零重训）：消除 C10 振荡 + 抬升边界 Vdc + 抗噪声门控。
2. **多机开关级复核 + 直流互联（dual-DC-pool）**：这是 Mode 5/协调价值真正体现处，也是深对称单端口预算边界的**物理解**
   （见仓库 `lab/simulink/hpt_dual_dcpool*.slx` 与 §5 dual-DC-pool 工作）。优先级最高的"增量科学价值"。
3. **门控保护**：默认启用 hysteresis+slew（噪声下 raw 抖振；slew 必需）。
4. **训练分布扩展**（连续网络凹陷 + 多机耦合 + 噪声观测）：相量鲁棒性已成立，优先级中等；
   若要 Mode 5 在网络层也优于固定律，需把网络耦合/直流互联纳入训练。
5. **不建议**：继续纯相量层网络扫描 —— 价值已饱和（Mode 5 网络层 ≈ 固定律）。

## 一句话
> 单装置 Mode 5 已证明可安全嵌入小配网（鲁棒性，相量层 + 代表性开关级）；要论证其**系统级优越性**，
> 须移到**多机开关级 + 直流互联**层面，并在该层面重新做对比与（必要时）训练分布扩展。
